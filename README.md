## Overview

RATR is a training-free material rebinding framework built upon a frozen
two-image editor.

Our approach reorganizes target and material-reference conditions according
to their distinct roles, aiming to preserve target geometry and identity while
transferring the visible material appearance of the reference.

The current repository serves as the project page and result gallery.
Code and additional resources will be released later.
